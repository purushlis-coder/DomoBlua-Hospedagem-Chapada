# Fluxo de Processos Ponta a Ponta (SOP)

> O "filme" de uma reserva, do clique do hóspede à avaliação — mostrando **quem faz o quê e quando**.
> 🤖 = automático (Airbnb) · 🧑‍💼 = Gestor (Purush, remoto) · 🧹 = Secretária do lar (**Talita Torres**, presencial) · 🆘 = Apoio de confiança local (urgência).

## Linha do tempo de uma reserva

| Momento | Quem | Ação |
|---------|------|------|
| Reserva confirmada | 🤖 | Envia **M1** (confirmação) automaticamente |
| Reserva confirmada | 🧑‍💼 | Confere perfil do hóspede; bloqueia janela de limpeza no calendário |
| 2 dias antes | 🤖 | Envia **M2** (pede dados p/ portaria, carro) |
| ~1 dia antes | 🧑‍💼 | **Cadastra o hóspede na portaria 24h** (nome, documento, datas, placa) |
| ~1 dia antes | 🧑‍💼 | Confirma com a 🧹 que o apê está pronto (fotos da última troca OK) |
| Dia do check-in 10h | 🤖 | Envia **M3** (endereço, **senha da fechadura**, Wi-Fi) |
| Dia do check-in | 🧑‍💼 | Gera a **senha temporária** da fechadura para a estadia |
| Dia do check-in 19h | 🤖 | Envia **M4** (boas-vindas / "entrou tudo certo?") |
| Durante a estadia | 🧑‍💼 | Responde dúvidas (respostas salvas); resolve o que surgir |
| Estadia longa (a cada 15d) | 🧑‍💼/🧹 | **M7** + limpeza intermediária opcional |
| 1 dia antes da saída | 🤖 | Envia **M5** (lembrete de check-out) |
| Check-out (até 11h) | hóspede | Sai; senha expira |
| Após o check-out | 🧑‍💼 | Aciona a 🧹 (data e prazo até o próximo hóspede) |
| Pós-saída | 🧹 | **Turnover**: vistoria → limpeza → preparo → fotos → registro (Forms) |
| Pós-turnover | 🧑‍💼 | **Audita** as fotos/registro; só então libera o próximo acesso |
| Check-out 14h | 🤖 | Envia **M6** (pedido de avaliação) |
| Após avaliação | 🧑‍💼 | Responde/avalia o hóspede; anota melhorias |

## Pontos de controle (gates) que protegem a qualidade
1. **Antes da chegada:** hóspede cadastrado na portaria + apê comprovadamente pronto (fotos).
2. **Antes de liberar o próximo acesso:** fotos da troca auditadas pelo gestor.
3. **Antes de subir o preço:** reputação recuperada (5–8 avaliações 5★).

## Escalonamento de urgência (sempre)
```
Ocorrência → 🧹 Secretária tenta resolver/avalia o nível
  ├─ 🟢 rotina → registra no Forms
  ├─ 🟡 importante → 🧑‍💼 Gestor (WhatsApp, foto)
  └─ 🔴 urgente → 🧑‍💼 Gestor (ligação)
         ├─ se Gestor não responde → 🆘 apoio de confiança local assume a decisão
         └─ risco imediato (gás/incêndio/água) → portaria 24h + emergência NA HORA
```

## Cadência do Gestor (remoto) — o mínimo para manter a régua
- **A cada troca (5 min):** auditar fotos/registro, liberar acesso, ver alertas de estoque/dano.
- **Diário (2 min):** responder mensagens (meta: minutos), conferir check-ins/outs do dia.
- **Semanal (15 min):** preço/calendário, gastos de reposição, novas avaliações.
- **Mensal (30 min):** fechar o mês na planilha, separar 50% no Fundo, avaliar a secretária (bônus).

> Resultado: o hóspede tem uma experiência consistente, a secretária sabe exatamente o que fazer, e
> você administra tudo em **~10–15 min/dia** de onde estiver.
