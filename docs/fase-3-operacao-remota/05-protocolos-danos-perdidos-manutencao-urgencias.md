# Protocolos: Danos, Achados e Perdidos, Manutenção e Urgências

> Regra-mãe de tudo: **registrar com evidência (foto/vídeo + data) e comunicar no nível certo.**

## 1. Níveis de urgência (como comunicar)

| Nível | Exemplos | Como avisar | Prazo |
|-------|----------|-------------|------:|
| 🔴 **Urgente** | Vazamento, sem luz/água, fechadura travada, hóspede sem acesso, cheiro de gás, alagamento | **Ligar** + WhatsApp com foto | Imediato |
| 🟡 **Importante** | Item quebrado/sumido, dano achado, falta de estoque crítico, eletro com defeito | WhatsApp com foto | Mesmo dia |
| 🟢 **Rotina** | Desgaste leve, lâmpada queimada, reposição comum, observação | Registrar no Google Forms | No turnover |

## 2. Danos causados por hóspede
Detectar **na vistoria de saída** (antes de limpar), enquanto dá para ligar o dano ao hóspede que saiu.

**Passo a passo:**
1. **Não limpe nem conserte ainda.** Fotografe o dano (foto aberta + de perto).
2. Avise o gestor no nível 🟡 (ou 🔴 se for grave) com as fotos.
3. O gestor decide se aciona a **Central de Resoluções / AirCover do Airbnb** (tem prazo curto — por isso a pressa).
4. Só depois, limpar/isolar o item.

> Importante: o pedido de reembolso por dano no Airbnb tem **prazo** e exige **fotos com data**. A
> vistoria de saída fotografada é o que viabiliza o ressarcimento.

## 3. Achados e perdidos
1. Guardar o item em **saco plástico etiquetado** com a **data e o nome do hóspede** (se souber).
2. Fotografar e registrar no Forms.
3. Gestor avisa o hóspede pelo Airbnb e combina devolução (correio por conta do hóspede / retirada).
4. Guardar por **até 30 dias**; depois, descartar/doar conforme orientação do gestor.

## 4. Identificação de manutenção (preventiva e corretiva)
A diarista é os "olhos" do imóvel. A cada turnover, checar e reportar (🟢, ou 🟡 se atrapalha o uso):

| Verificar | Sinal de alerta |
|-----------|-----------------|
| Chuveiro / torneiras | Pingando, pressão fraca, crosta de cal |
| Vaso / descarga | Vazando, não vedando |
| AC | Não gela, pinga dentro, barulho, filtro sujo |
| Frigobar | Não gela, faz gelo demais, borracha solta |
| Cooktop/fogão | Boca não acende, registro duro |
| Tomadas/interruptores | Soltos, esquentando, sem energia |
| Portas/fechaduras/janelas | Emperrando, folga, vedação |
| Infiltração/mofo | Mancha em parede/teto, cheiro |
| Móveis | Puxador solto, dobradiça, perna bamba |

> **Preventivo trimestral** (combinar): limpar filtro do AC, verificar vedações do box, testar
> detector de fumaça, descalcificar chuveiro/cafeteira.

## 5. Como registrar evidências (padrão)
- Sempre **foto + data**. Para defeito que "aparece funcionando", gravar **vídeo curto**.
- Nomear/descrever: *o quê, onde, desde quando (se souber)*.
- Guardar na pasta da reserva ou no álbum "Manutenção".

## 6. Árvore de decisão rápida (para a diarista)
```
Encontrou algo?
 ├─ Risco a pessoas/imóvel agora? (água, gás, luz, acesso) → 🔴 LIGAR já
 ├─ Quebrou / sumiu / dano de hóspede / eletro parado?     → 🟡 WhatsApp com foto hoje
 └─ Desgaste leve / reposição / observação                 → 🟢 registrar no Forms
```
