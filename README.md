# Projeto Airbnb Brasília — Reativação, Operação Remota e Expansão Patrimonial

Repositório de gestão estratégica e operacional de um apartamento no **Plano Piloto, Brasília/DF**,
anunciado no Airbnb (anúncio [51861083](https://www.airbnb.com.br/rooms/51861083)), que volta a operar
como hospedagem de curta temporada a partir de **julho de 2026** após ~1 ano com inquilino fixo.

O objetivo não é apenas "ganhar dinheiro com Airbnb", e sim construir um **modelo replicável**:
operar este imóvel com máxima automação e baixa dependência física, gerar caixa previsível e usar
~50% da renda líquida para formar a entrada de um **segundo imóvel no Plano Piloto (R$ 300–400 mil)**.
